# Setup for @moeinnrz

## 1. Create the profile repository

Create a **public** repository named exactly:

`moeinnrz`

GitHub only displays a profile README automatically when the repository is public, the repository name exactly matches the username, and a non-empty `README.md` exists in its root.

## 2. Upload the files

Copy these paths into the repository:

- `README.md`
- `assets/header.svg`
- `.github/workflows/snake.yml`

## 3. Commit to `main`

The first push triggers the snake workflow. It creates an `output` branch containing the generated SVG files.

## 4. Check the workflow

Open **Actions → Generate contribution snake** and confirm the workflow finishes successfully.

## 5. Optional profile polish

In your GitHub profile settings, keep your public bio and LinkedIn link up to date and pin the repositories you most want recruiters/visitors to see.

## Notes

- The README uses live image services for stats/activity cards; they update automatically as GitHub data changes.
- The snake is generated by GitHub Actions and published to the `output` branch.
- `count_private=true` is included in the stats URL, but the profile page should not claim private contributions as public facts; the exact visible result depends on GitHub's privacy settings and the stats service.
