# Updating @moeinnrz profile

You already have the profile repository. This package is an improved version of the same profile, not a new repository.

## Replace these files

Upload/replace:

- `README.md`
- `assets/header.svg`
- `.github/workflows/snake.yml`

You can keep `SETUP.md` or delete it from the public repository.

## Important

Repository name must remain exactly `moeinnrz` and it must remain public.

After committing the changes:

1. Open the repository's **Actions** tab.
2. Run **Generate contribution snake** manually once with **Run workflow**.
3. Wait for the workflow to finish.
4. Open `https://github.com/moeinnrz` and hard-refresh the page if the old README is still cached.

The README intentionally uses a more editorial/portfolio-style layout: large visual header, numbered sections, two-column project cards, grouped capabilities, cleaner technology sections and restrained statistics.
